# Flight Management Computer (FMC)

An educational Flight Management Computer  simulator developed with Python and Tkinter.

# About the Project

This project simulates the basic functions and interface of an FMC for educational purposes.

The current flight parameters and simulation values are not based on real-world flight data. In future development, these parameters are planned to vary according to different aircraft types and their performance characteristics.

The project is currently under active development, with new features and improvements being added.

# Features

- Route management
- Airport and waypoint input
- Flight progress information
- VNAV simulation
- Fuel monitoring
- Flight simulation controls
- FMC-style graphical interface

# Technologies

- Python
- Tkinter
